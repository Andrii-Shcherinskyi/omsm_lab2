## Вміст репозиторію
- `омсм2.ipynb` — ноутбук з підготовкою даних, навчанням YOLOv8n і YOLOv8s та оцінкою
- `best.pt`, `last.pt` — збережені ваги моделі
- `args.yaml`, `results.csv`, `results.png` — параметри та криві навчання
- `yolo_comparison_table.csv`, `fp_fn_table.csv` — метрики на тесті та аналіз помилок
- `yolo_errors.png`, `my_detections.png` — приклади помилок та інференсу на власних фото
- `video_detections.gif`, `video_yolov8n.mp4`, `video_yolov8s.mp4` — детекція на відео
